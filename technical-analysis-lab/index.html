TECHNICAL ANALYSIS LAB

Technical indicators, learned and built independently

This page is a student project - a working record of the indicators I taught myself while studying capital markets and trading analytics. Each card below is one indicator, implemented from first principles in script.js, with its own mini-chart running on live simulated data rather than a static image.

01

Trend Direction

TREND

Moving Average (MA)

A simple moving average smooths raw price into a single line, which is my primary tool for noise filtering before I trust any directional read. I use a 20-period SMA as a stable baseline - when price holds above it, that's my base case for trend continuation. 

const sma20 = sma(closes, 20).at(-1);
trendBase = price > sma20 ? 'holding above' : 'below baseline';
TREND

Exponential Moving Average (EMA)

The EMA weights recent price more heavily, so it reacts faster than a simple average. I run a 50-period EMA alongside my SMA specifically to catch early trend shifts before the slower baseline confirms them. 

const ema50 = ema(closes, 50).at(-1);
shiftEarly = crossedAbove(price, ema50);
02

Momentum & Reversal

MOMENTUM

Relative Strength Index (RSI)

RSI-14 measures the speed and size of recent price changes on a 0–100 scale. I use it to flag overbought extremes above 70 and oversold extremes below 30 - my signal that a move is stretched and due to cool off. 

const rsiVal = rsi(closes, 14).at(-1);
state = rsiVal > 70 ? 'overbought' : rsiVal < 30 ? 'oversold' : 'neutral';
MOMENTUM

Moving Average Convergence Divergence (MACD)

MACD tracks the relationship between two EMAs to surface momentum shifts before price fully confirms them. A histogram crossing zero, or a signal-line cross, is usually the earliest read I get that momentum is turning. 

const { hist } = macd(closes, 12, 26, 9);
turning = hist.at(-2) < 0 && hist.at(-1) >= 0;
03

Confirmation

CONFIRMATION

Volume Analysis

Price movement without volume behind it rarely holds. Comparing each bar to its 20-bar average is how I run breakout validation - my simplest filter for confirming a move instead of chasing it on price alone. 

const vol = bars.at(-1).volume;
const avg20 = sma(volumes, 20).at(-1);
confirmed = vol > avg20;
