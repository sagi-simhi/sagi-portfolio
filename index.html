Projects

01 Interactive Dashboard

Factor-Tilted Portfolio Dashboard

An interactive research model for examining a long-term global investment allocation (80% FTSE All-World, 20% Small-Cap Value) against the S&P 500 and MSCI ACWI using a calibrated synthetic return model.

Question Does a small-cap value tilt on top of a global core actually earn its keep against plain benchmark indices - and is that easier to judge by watching it than reading about it?
Approach Modeled an 80/20 FTSE All-World / Small-Cap Value allocation with a calibrated, regime-based return model and built an interactive dashboard to compare its simulated behavior with the S&P 500 and MSCI ACWI.
Reads Simulated CAGR, Sharpe ratio, and drawdown, compared side-by-side with both benchmarks over the selected model window.

02 Quantitative Lab

Technical Analysis Lab

A quantitative sandbox showcasing self-taught technical indicators (MA, EMA, RSI, MACD, Volume) implemented from first principles with live animated visual previews for market timing and trend confirmation.

Question Understanding a technical indicator from a textbook definition is different from understanding what it does to a live chart - can building each one from scratch close that gap?
Approach Implemented MA, EMA, RSI, MACD, and Volume from first principles rather than importing a charting library, so each indicator's behavior is fully owned and inspectable.
Reads Live animated previews layered over price action, used for trend confirmation and market-timing signals.
