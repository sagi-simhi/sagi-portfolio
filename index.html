01 Interactive Dashboard

Factor-Tilted Portfolio Dashboard

An interactive web dashboard built to track and visualize a long-term global investment portfolio (80% FTSE All-World, 20% Small-Cap Value) benchmarked against the S&P 500 and MSCI ACWI.

Question Does a small-cap value tilt on top of a global core actually earn its keep against plain benchmark indices - and is that easier to judge by watching it than reading about it?
Approach Modeled an 80/20 FTSE All-World / Small-Cap Value allocation and built a live dashboard to track it continuously against the S&P 500 and MSCI ACWI, rather than reviewing it in a spreadsheet on a fixed schedule.
Reads CAGR, Sharpe ratio, and drawdown, tracked side-by-side against both benchmarks.
